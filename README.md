# NOTX MINER: অটো পেআউট backend (Render + Python)

বট থেকে withdraw রিকোয়েস্ট এলে এই সার্ভিস আপনার **হট ওয়ালেট** থেকে সরাসরি **NOT jetton** পাঠায় (Oxapay বা অন্য কোনো মধ্যস্থ ছাড়া)। খরচ শুধু প্রতিটি পেআউটে প্রায় 0.05 TON গ্যাস, এর অব্যবহৃত অংশ ওয়ালেটে ফেরত আসে।

## কীভাবে কাজ করে

```
User ──withdraw──▶ Bot (TBC)
                    │ লিমিটের ভেতরে হলে: wd_push
                    ▼
            POST /payout  (API key সহ)  ──▶  Render backend ──▶ TON blockchain
                                                  │
Bot ◀──── wd_result (webhook, Callback key সহ) ◀───┘  paid / failed / review
```

- লিমিটের ভেতরে হলে অটো, লিমিটের উপরে হলে আগের মতো **ম্যানুয়াল কিউ**।
- backend প্রতিটি `request_id` **একবারই** পে করে (MongoDB লেজার)। একই রিকোয়েস্ট আবার এলে শুধু আগের ফলাফল ফেরত দেয়।
- রিস্টার্টের সময় `sending` অবস্থায় আটকে থাকা রিকোয়েস্ট **কখনো অটো-রিট্রাই হয় না**, `review` এ যায়।
- কোনো সমস্যা হলে রিকোয়েস্ট **ম্যানুয়াল কিউর মাথায়** চলে যায় এবং দুই অ্যাডমিনের কাছে অ্যালার্ট যায়। কিছু অটো-রিফান্ড হয় না, অ্যাডমিন সিদ্ধান্ত নেয়।
- নিরাপত্তার দ্বিতীয় স্তর: backend-এও `MAX_PER_PAYOUT_NOT` আর `DAILY_MAX_NOT` সীমা আছে। বটের সিক্রেট ফাঁস হলেও এর বেশি টাকা বের হবে না।

## সেটআপ (একবারের কাজ)

### ১. ওয়ালেট আর সিক্রেট কী ঠিক করুন

**ওয়ালেট:** আপনার নিজের Tonkeeper ওয়ালেটের **v4R2** অ্যাড্রেস ব্যবহার হবে (W5 নয়)।
- wallet.tonkeeper.com → Settings → **Active address** → v4R2 এর পাশে **Add**
- ২৪ শব্দ: Tonkeeper → Settings → **Backup / Recovery phrase**

> ⚠️ ওই ২৪ শব্দ Render-এ বসালে সেই ২৪ শব্দের **সব ভার্সনের ওয়ালেট** (v4R2, W5 সহ) ঝুঁকিতে থাকে। তাই এই ওয়ালেটে **অল্প টাকাই রাখুন**, আর বড় ব্যালেন্স অন্য ওয়ালেটে রাখুন।

**সিক্রেট কী (`API_KEY`, `CALLBACK_KEY`):** দুটো আলাদা, প্রতিটি **৩২+ অক্ষরের** র‍্যান্ডম স্ট্রিং।
- Blueprint (`render.yaml`) দিয়ে ডিপ্লয় করলে Render নিজেই বানিয়ে দেয়। Render → Environment থেকে মান কপি করে বটে বসান।
- হাতে বানালে যেকোনো পাসওয়ার্ড জেনারেটর (যেমন Bitwarden বা Google-এর Suggest strong password) দিয়ে দুটো আলাদা স্ট্রিং নিন।

### ২. ওয়ালেটে ফান্ড দিন
- প্রায় **0.5 TON** (গ্যাসের জন্য)
- যত NOT পেআউটে লাগবে (আপাতত অল্প)
- তারপর ওয়ালেট থেকে **একটা ছোট TON ট্রান্সফার** করুন (যেমন নিজের অন্য ওয়ালেটে 0.01 TON), তাহলে ওয়ালেট কন্ট্রাক্ট ডিপ্লয় হবে। না করলে backend "wallet is not deployed" বলবে।

### ৩. MongoDB Atlas
- নতুন একটা ডাটাবেস ইউজার বানিয়ে connection string নিন (`mongodb+srv://...`)
- Network Access এ `0.0.0.0/0` দিন (Render ফ্রি-তে IP বদলায়)

### ৪. (ঐচ্ছিক) Toncenter API key
টেলিগ্রামে **@tonapibot** থেকে বিনামূল্যে নেওয়া যায়। না দিলে ১ রিকোয়েস্ট/সেকেন্ডের সীমা থাকে, তবে কাজ চলে।

### ৫. Render-এ ডিপ্লয়
1. এই ফোল্ডারটা একটা GitHub রিপোতে পুশ করুন (**`.env` বা মনিক কখনো কমিট করবেন না**)।
2. Render → New → Web Service (বা Blueprint, `render.yaml` আছে) → রিপো দিন।
3. Environment variables দিন (`.env.example` দেখুন):

| নাম | মান |
|---|---|
| `WALLET_MNEMONIC` | Tonkeeper-এর ২৪ শব্দ (স্পেস দিয়ে এক লাইনে) |
| `API_KEY` | ধাপ ১-এর র‍্যান্ডম স্ট্রিং |
| `CALLBACK_KEY` | ধাপ ১-এর আরেকটি র‍্যান্ডম স্ট্রিং (API_KEY থেকে আলাদা) |
| `MONGODB_URI` | Atlas string |
| `BOT_WEBHOOK_URL` | ধাপ ৭-এ পাবেন, পরে বসাবেন |
| `TONCENTER_API_KEY` | ঐচ্ছিক |
| `MAX_PER_PAYOUT_NOT`, `DAILY_MAX_NOT` | আপনার সীমা (ডিফল্ট 5000 / 50000) |

4. ডিপ্লয় শেষে `https://আপনার-সার্ভিস.onrender.com/health` খুললে `{"ok":true,...,"wallet":"UQ..."}` দেখা যাবে। ওই অ্যাড্রেস ধাপ ২-এর ওয়ালেটের সাথে মিলছে কিনা দেখে নিন।

### ৬. ঘুমিয়ে পড়া ঠেকান (Render ফ্রি)
ফ্রি সার্ভিস ১৫ মিনিট নিষ্ক্রিয় থাকলে ঘুমায়। **UptimeRobot** (ফ্রি) এ `https://আপনার-সার্ভিস.onrender.com/health` ৫ মিনিট পরপর ping করান। (ঘুমালেও বট ৩ বার রিট্রাই করে, কিন্তু জাগিয়ে রাখলে নির্ভরযোগ্য।)

### ৭. বটের সেটআপ
নতুন `notx_miner_bot.json` ইমপোর্ট করুন, তারপর **Admin → Auto payout**:
1. **Backend URL**: Render-এর ঠিকানা (`https://...onrender.com`)
2. **API key**: Render-এর `API_KEY` (বট আপনার মেসেজ অটো ডিলিট করে)
3. **Callback key**: Render-এর `CALLBACK_KEY`
4. **Max per request** আর **Daily cap**: NOT-এ (বটের সীমা, backend-এর সীমার চেয়ে কম বা সমান রাখুন)
5. **Webhook URL** চাপুন, যে ঠিকানা আসবে সেটা Render-এ `BOT_WEBHOOK_URL` হিসেবে বসান, সার্ভিস রিস্টার্ট দিন
6. **Test backend** চাপুন। সফল হলে ওয়ালেট অ্যাড্রেস, TON আর NOT ব্যালেন্স দেখাবে
7. একটা **ছোট নিজের টেস্ট withdraw** করুন (অটো ON করে), ব্লকচেইনে দেখে নিশ্চিত হোন
8. তারপর **Turn ON**

## "needs you" অ্যালার্ট এলে কী করবেন
অ্যালার্টে লেখা থাকে টাকা পাঠানো হয়নি, নাকি হয়ে থাকতে পারে।
- **"Nothing was sent"**: নিশ্চিন্তে ম্যানুয়ালি পাঠান বা reject করে রিফান্ড দিন।
- **"may already have been sent"**: **আগে** [tonviewer.com](https://tonviewer.com) এ হট ওয়ালেটের হিস্ট্রি দেখুন, না পাঠানো থাকলে তবেই ম্যানুয়ালি দিন। backend-এর `GET /payout/<id>` (header `X-Api-Key`) ও অবস্থা বলে দেয়। পরে যদি backend-এর `paid` ফলাফল আসে, বট নিজেই রিকোয়েস্টটা শেষ করে দেয়।

## স্ট্যাটাস
| status | মানে |
|---|---|
| `queued` / `sending` | প্রক্রিয়াধীন |
| `paid` | ওয়ালেট ট্রান্সফার নিয়েছে (seqno বেড়েছে)। tx হ্যাশ পাওয়া গেলে ইউজার Tonviewer লিংক পায় |
| `failed` | কিছুই পাঠানো হয়নি (ব্যালেন্স কম, ঠিকানা ভুল ইত্যাদি) |
| `review` | পাঠানো হয়ে থাকতে পারে, মানুষের যাচাই দরকার |

## টেস্ট
```
python -m unittest discover -s tests -v
```
এগুলো নকল ওয়ালেট আর নকল ডাটাবেসে চলে (ব্লকচেইন লাগে না)।

## সৎ সীমাবদ্ধতা (দয়া করে পড়ুন)
- যে পরিবেশে এটা বানিয়েছি সেখানে PyPI ব্লক ছিল, তাই `tonsdk` ইনস্টল করে **আসল ব্লকচেইন কোড চালানো যায়নি**। `chain.py` tonsdk-র সোর্স আর Toncenter API মিলিয়ে লেখা, কিন্তু প্রথমবার **অল্প NOT দিয়ে নিজে টেস্ট করুন**। কোনো ধাপে এরর এলে backend-এর Render লগ আর বটের অ্যালার্ট দেখলেই কারণ পাওয়া যাবে।
- ওয়ালেট শুধু **v4r2** (বা v3r2) সমর্থিত। W5 নয়। Tonkeeper-এ v4R2 অ্যাড্রেস Add করে সেটাই ফান্ড করুন।
- TBC-র `HTTP.post` আর webhook-এর ডেটার আকার ডক্সে স্পষ্ট নেই। বট একাধিক কল-স্টাইল চেষ্টা করে, আর ফলাফল না বুঝলে নিরাপদ পথে (ম্যানুয়াল কিউ) যায়। **Test backend** বাটন দিয়ে আগে যাচাই করে নিন।
- Render ফ্রি-তে একটাই instance চালান (`--workers 1`), নইলে একাধিক ওয়ার্কার একই ওয়ালেটের seqno নিয়ে ঝামেলা করতে পারে।
